# Enterprise Networking Journal Presentation

Publication-quality PowerPoint for ECNetBench and the Enterprise Cognitive Network (ECN-v3).

## Output

- `Network_Journal_Presentation.pptx` — presentation deck
- `diagrams/` — architecture diagrams (PNG + PDF)
- `assets/` — verified scientific figures copied from `paper/overleaf/figures/`

## Build

From the repository root:

```bash
python presentation/generate_architecture_diagrams.py
python presentation/build_network_journal_presentation.py
```

The build script regenerates diagrams, assembles the deck from verified metrics in
`results/manuscript_ready_numbers.json`, and validates figure presence and numeric consistency.

## Traceability

| Scientific figure | Source |
|---|---|
| `baseline_auprc_mean_ci.png` | `paper/overleaf/scripts/regenerate_pub_figures_v3.py` |
| `architecture_selection_t1.png` | same |
| `module_contribution.png` | same |
| `T1_*` / `T2_*` / `T3_*` curves | same (from `results/per_seed/*.json`) |

Architecture diagrams are generated by `generate_architecture_diagrams.py` for illustration
of system structure (not experimental result plots).

## Final architecture (deck numbers)

- T1: leakage-safe enriched features + anchored fusion (`ECNFusionModel`)
- T2: telemetry logistic regression
- RCA: RF + TreeSHAP
- Stacking: ablation / negative result
