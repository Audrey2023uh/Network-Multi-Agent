\section{Conclusion}
\label{sec:conc}

We presented ECNetBench and an Enterprise Cognitive Network (ECN-v3) digital-twin multi-agent framework evaluated under leakage-safe multi-seed protocols. Exact verified means show final T1 AUPRC $0.11522078115707056$ for leakage-safe enriched features with anchored fusion, exceeding random forest $0.07583814878524626$ and the v2 configuration $0.05771284608153401$. Stacking on the same enriched features is a negative ablation ($0.0997458645152051$). Added deep baselines---TabNet ($0.0492$) and true GraphSAGE ($0.0152$)---do not overturn these selections. The recommended T2 head is telemetry logistic regression ($0.038043099063649714$). RCA uses RF with TreeSHAP. The primary scientific value is a reproducible benchmark plus a complete cognitive NetOps pipeline with evidence-selected fusion and honest statistics---not a universal detector champion. Future work includes larger topologies, production-trace calibration, richer temporal GNNs, and human-in-the-loop healing studies.
